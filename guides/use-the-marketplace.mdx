title: "Use the marketplace"
description: "Find a ready-made skill, clone it into your workspace, rate it, or share your own."

The **marketplace** is a public library of skills and workflows. Instead of building a skill yourself, find one that does what you need and clone it into your workspace. The copy is yours to run and change. Your changes do not affect the original, and changes to the original are not pushed to your copy.

## Browse

Open **Marketplace** from the main sidebar. It has two tabs:

- **Skills**: single skills you can clone, then run.
- **Workflows**: workflows other people have shared.

The **Skills** tab lists public skills you can search and sort by **Trending**, **Most Runs**, **Recent**, or **Most reliable**. Each card shows the skill's name, description, creator, and a one-line [track record](#track-record), such as "Worked 18 of 20 recent runs · ~6s · checked 2 h ago". Click a card to open the skill's page, which shows its full track record, total runs, clones, rating, and credits per run.

<Tip>
  Search by the site name, the kind of data, or the task.
</Tip>

From code or an AI assistant, find a skill by its task with [Find a skill for a task](/api-reference/marketplace/search) or the `search_skills` [MCP tool](/ai-assistants/mcp-tools#marketplace). Find a workflow the same way with `kind=workflow` or the `search_workflows` tool.

Anyone may read a public skill or workflow. You run only your own copy. Clone it first with [Clone a skill](/api-reference/skills/clone) or [Clone a workflow](/api-reference/workflows/clone) (MCP tools: `clone_skill`, `clone_workflow`), then run the copy. A run of a public skill you have not cloned returns `403` `clone_required`.

## Track record

Every public skill shows how it has done on real runs, so you can decide whether to trust it before you clone it. The numbers come only from runs that really happened. Nothing is run to make them, and nothing is added to them.

**Which runs count**

- The skill's own runs, and the runs of the copies people cloned from the marketplace. A copy runs the same steps, so its runs say whether the skill works. Only totals are shown: never anyone's inputs, rows, or name.
- Finished runs only. A cancelled run and a run still going are not counted.
- Not counted: runs that failed on our side, runs stopped by the person or by inputs the skill could not use, answers served from the cache, and repair checks. Of the test runs made while the skill was being built, only the last one counts.

**What the numbers mean**

| Number | What it is |
| --- | --- |
| Recent runs that worked | Of the last 20 counted runs, how many worked. A run that came back with fields missing counts as a failure, as does a run that failed. |
| Last 30 days | The same, over the counted runs of the last 30 days. |
| Typical run time | The median time from start to rows of the recent runs that worked. "9 in 10 within" is the 90th percentile. |
| Typical result | The median number of rows, and the median credits, of the recent runs that worked. |
| Last worked | When a run last worked. |
| Last checked | When the newest counted run ran. |
| Recent runs | The last 20 counted runs, oldest first: green worked, yellow came back with fields missing, red failed. |

**Status**

- **Working**: 80% or more of the recent runs worked.
- **Some failures**: 50% to 79% worked.
- **Failing**: under 50% worked.
- **Not enough runs yet**: fewer than 5 counted runs. No percentage is shown until then, so one lucky run never reads "100%".

**Most reliable** sorts skills with 5 or more counted runs first, then by the share that worked, then by how many runs they have. In a search, a skill whose status is **Working** ranks a little higher among the skills that do the task.

The same numbers are in the API and MCP: `proof` on [Find a skill for a task](/api-reference/marketplace/search) and [Get a skill](/api-reference/skills/get), and one "Track record:" line in the text of the `search_skills` and `get_skill` [MCP tools](/ai-assistants/mcp-tools#marketplace). They are read again about once a minute.

## Clone a skill

<Steps>
  <Step title="Find a skill">
    Browse or search the marketplace. To narrow it down, click a [category](/concepts/skills#categories) in the list on the left (on a phone, the row of categories above the skills); each shows how many skills it has. Click a card to open the skill's page and check its inputs, sample output, and rating.
  </Step>
  <Step title="Click Clone skill">
    On the skill's page, click **Clone skill** in the top-right corner, then **Clone skill** again to confirm. The copy goes into the workspace you are in.
  </Step>
  <Step title="Open your copy">
    After cloning, you land on the copy in **My skills**. Its header has a **Rate on Marketplace** button. Use it after you run the skill to leave a review.
  </Step>
  <Step title="Customize and run">
    The copy is fully yours. Change its name, inputs, and instructions with **Edit skill**. Run it to check it does what you need, then schedule it or call it from the API.
  </Step>
</Steps>

<Note>
  Runs of a cloned skill use your credits, not the author's, the same as your own skills. See [Credits](/concepts/credits).
</Note>

## Rate a skill you cloned

After you run a cloned skill, click **Rate on Marketplace** on the skill's page to give it stars and a written review. Only people who cloned a skill can rate it, so ratings come from people who used it. Your rating counts toward the skill's score in the marketplace.

## Share your own skill

To share a skill you built, make it public. There are two ways:

- **When you publish it**: in the **Publish Skill** dialog, set visibility to **Public**, then click **Publish**. It shows in the marketplace right away.
- **Later**: open the skill, click **Edit skill**, and change visibility from **Private** to **Public**. It shows in the marketplace when you save.

Anyone on Valendata can find a public skill. Others can read it, and run it after they clone it into their own workspace.
