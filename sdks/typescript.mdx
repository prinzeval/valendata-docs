# TypeScript SDK

```bash
npm install @valendata/sdk
```

## Usage

```typescript
import { Valendata } from "@valendata/sdk";

const valendata = new Valendata({
  apiKey: process.env.VALENDATA_API_KEY!,
});

const result = await valendata.skills.run({
  task: "Go to producthunt.com and get top 5 products today",
  outputFormat: "json",
});

console.log(result.data);
```
