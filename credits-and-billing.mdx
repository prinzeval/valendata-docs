Valendata uses a credit-based, pay-for-what-you-use billing model. Every action a run takes is metered separately and priced in credits, listed exactly below — no bundled flat fees, no hidden categories.

## What credits cover

Every time you trigger a Skill or Workflow, Valendata deducts credits based on the exact resources that run consumed. A session held open (including idle gaps between steps) is billed for the time it's reserved, not just moments of active output — this is metered the same way whether a workflow step, a Skill run, or an interactive chat session holds the browser open.

### AI model usage

Cost depends on which model you (or your automation) selects, and scales with tokens used:

| Model | Input (credits / 1k tokens) | Output (credits / 1k tokens) |
| --- | --- | --- |
| Gemini 3 Flash *(default — fast & smart)* | 0.125 | 0.75 |
| Gemini 3.1 Pro *(most capable Gemini)* | 0.50 | 3.00 |
| Claude Sonnet 4.6 *(balanced Claude)* | 0.75 | 3.75 |
| Claude Opus 4.6 *(advanced reasoning)* | 1.25 | 6.25 |
| Claude Opus 4.7 *(maximum intelligence)* | 1.25 | 6.25 |

Bring-your-own-key (BYOK) users pay their own provider directly for tokens; the model picker still applies for capability, but token cost is between you and your provider.

### Browser & proxy time

| Resource | Cost |
| --- | --- |
| Browser session time | 2.0 credits / minute |
| + Sticky Identity proxy *(stays logged into one site as a stable IP)* | +2.2 credits / minute, on top of browser time |
| + Rotating Residential proxy *(avoids bot bans / rate limits)* | +2.9 credits / minute, on top of browser time |

Not every task needs a proxy — Valendata decides automatically based on what the task requires, and the surcharge only applies for the actual minutes a proxy tier is in use.

### Other metered actions

| Resource | Cost |
| --- | --- |
| Web search query | 2.0 credits / query |
| Sandbox code execution | 1.0 credit / execution |
| Extracted data row | 0.1 credit / row (10 rows = 1 credit) |
| CAPTCHA solve — reCAPTCHA v2 | 0.20 credits / solve |
| CAPTCHA solve — reCAPTCHA v3 | 0.25 credits / solve |
| CAPTCHA solve — Cloudflare Turnstile | 0.30 credits / solve |

CAPTCHA solves only happen (and only bill) when a task actually hits one — most tasks never touch this line at all.

Every new Valendata account receives **100 free credits** at sign-up, no credit card required. Use them to build and test your first Skills before choosing a plan.

## Credits never expire

**Purchased credits never expire.** If you buy 5,000 credits today and use 1,200 over the next month, your remaining 3,800 are still there, no deadlines, no cut-off dates. You can buy in bulk whenever it suits your budget.

Subscription plan credits work differently: they refresh each month on your billing date. Unused monthly credits do not carry over — every plan resets to its monthly grant each cycle. (Purchased top-up credits are separate from this and never expire, as above.)

## Checking your credit balance

Click the credit pill in the top header to open the **Credits & Billing** panel. From there you can view your transaction history, per-run breakdowns, and top up your balance. Credits are added immediately after payment.

## Frequently asked questions

<Accordion title="Do credits carry over if I buy a new bundle?">
  Yes. New credits are added to your existing balance. Credits from different purchases are pooled together and drawn down as a single balance — oldest credits are consumed first.
</Accordion>

<Accordion title="Is there a free tier?">
  There is no recurring free tier, but every account starts with 100 free credits. These are enough to run several Skills and evaluate the platform before purchasing a bundle.
</Accordion>

<Accordion title="How do Enterprise agreements work?">
  Enterprise plans offer volume pricing for 50,000 or more credits, custom SLAs, dedicated support, and invoiced billing. [Contact the Valendata team](https://app.valendata.com) to discuss your requirements.
</Accordion>
