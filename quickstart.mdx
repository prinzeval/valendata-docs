Get up and running with Valendata in just a few steps.

<Steps>
  <Step title="Get your API Key">
    Log in to the [Valendata Console](https://app.valendata.com), navigate to **Settings → API Keys**, and generate a new key.
    
    ```bash
    export VALENDATA_API_KEY="val_live_..."
    ```
  </Step>

  <Step title="Run a Browser Automation Task">
    Trigger an autonomous browser task directly via our REST API using standard HTTP requests:

    <CodeGroup>
    ```bash cURL
    curl -X POST https://api.valendata.com/v1/skills/run \
      -H "Authorization: Bearer $VALENDATA_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "task": "Go to quotes.toscrape.com, extract the first 3 quotes with authors, and return as JSON",
        "output_format": "json"
      }'
    ```

    ```python Python (requests)
    import os
    import requests

    response = requests.post(
        "https://api.valendata.com/v1/skills/run",
        headers={
            "Authorization": f"Bearer {os.environ['VALENDATA_API_KEY']}",
            "Content-Type": "application/json"
        },
        json={
            "task": "Go to quotes.toscrape.com, extract the first 3 quotes with authors, and return as JSON",
            "output_format": "json"
        }
    )

    print(response.json())
    ```

    ```javascript JavaScript (Fetch)
    const response = await fetch("https://api.valendata.com/v1/skills/run", {
      method: "POST",
      headers: {
        "Authorization": `Bearer ${process.env.VALENDATA_API_KEY}`,
        "Content-Type": "application/json"
      },
      body: JSON.stringify({
        task: "Go to quotes.toscrape.com, extract the first 3 quotes with authors, and return as JSON",
        output_format: "json"
      })
    });

    const data = await response.json();
    console.log(data);
    ```
    </CodeGroup>
  </Step>

  <Step title="Inspect Execution & Output">
    The response contains the final extracted data, session execution stats, and links to visual recording artifacts:

    ```json
    {
      "session_id": "ses_9a8f2bc0",
      "status": "completed",
      "duration_seconds": 4.2,
      "credits_used": 1,
      "data": [

          "author": "Albert Einstein"
        }
      ]
    }
    ```
  </Step>
</Steps>
