You will create a skill from one sentence, run it, and call it from your own code.

<Steps>
  <Step title="Sign up">
    Create an account at [app.valendata.com](https://app.valendata.com). New accounts get **100 free credits**, no card needed.
  </Step>
  <Step title="Create a skill from a sentence">
    Open **My Skills**, click **Create Skill** and choose **Describe it**. Say what it should do and which website, for example:

    - **What should it do?** Search for dentists in Austin and list their name, rating, and phone.
    - **Which website?** `https://www.google.com/maps`

    Valendata does the task once in a cloud browser, learns the steps, and checks that they work. This takes a few minutes. When it is ready, the skill has a **slug** (for example `austin-dentists`), its **inputs** (`city`), and its **output fields** (`name`, `rating`, `phone`).

    You can also call [`POST /v1/skills`](/api-reference/skills/create), or ask your own AI assistant. See [Create a skill](/guides/create-a-skill).
  </Step>
  <Step title="Run it in the app">
    Open the skill, change the input (try `Dallas`), and click **Run**. The rows appear in a table. If a field is missing, use **Improve**. See [Improve a skill](/guides/improve-a-skill).
  </Step>
  <Step title="Call it from code">
    Create an API key in **Settings → API Keys** (see [API keys](/account/api-keys)). Then run the skill and wait for the rows:

    <CodeGroup>

    ```bash curl
    curl -X POST "https://api.valendata.com/v1/skills/austin-dentists/run?max_results=5" \
      -H "Authorization: Bearer $VALENDATA_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"city": "Dallas"}'
    ```

    ```python Python
    import os, requests

    resp = requests.post(
        "https://api.valendata.com/v1/skills/austin-dentists/run",
        headers={"Authorization": f"Bearer {os.environ['VALENDATA_API_KEY']}"},
        params={"max_results": 5},
        json={"city": "Dallas"},
        timeout=600,
    )
    resp.raise_for_status()
    print(resp.json()["data"])
    ```

    ```typescript TypeScript
    const resp = await fetch(
      "https://api.valendata.com/v1/skills/austin-dentists/run?max_results=5",
      {
        method: "POST",
        headers: {
          Authorization: `Bearer ${process.env.VALENDATA_API_KEY}`,
          "Content-Type": "application/json",
        },
        body: JSON.stringify({ city: "Dallas" }),
      },
    );
    console.log((await resp.json()).data);
    ```

    </CodeGroup>

    ```json Response (shortened)
    {
      "status": "success",
      "data": [
        {"name": "Lone Star Dental", "rating": 4.8, "phone": "+1 214-555-0100"}
      ],
      "count": 1,
      "credits_charged": 3
    }
    ```
  </Step>
</Steps>
