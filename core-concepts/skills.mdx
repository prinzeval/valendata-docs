A **Skill** is a saved, reusable browser automation task. Rather than typing out instructions every time, you define the objective, parameterize dynamic inputs, and execute it on demand, on a schedule, or via API.

## Defining a Skill

When creating a Skill, you provide a clear title and natural language task prompt.

```markdown
Go to {{target_url}} and extract all job postings with:
- Job Title
- Company Name
- Location
- Salary Range (if visible)
- Application URL

Return the results as a JSON array.
```

### Parameter Syntax: `{{variable}}`

Parameters allow you to vary inputs across executions without modifying the underlying prompt:

- `{{target_url}}`: Target website or starting link.
- `{{search_query}}`: Search keyword or query string.
- `{{max_items}}`: Limiting count for data extraction.

When triggering the skill from the console or API, you simply pass the corresponding JSON object:

```json
{
  "inputs": {
    "target_url": "https://news.ycombinator.com/jobs",
    "max_items": 10
  }
}
```

<Tip>
Be specific about the fields and format you need. Clear structural prompts reduce step count, shorten run duration, and minimize token costs.
</Tip>

## Running a Skill via API

Every Skill has a direct HTTP API endpoint that accepts dynamic parameters and returns structured extraction results:

**Endpoint**: `POST https://api.valendata.com/v1/skills/{slug}/run?max_results=10`

<CodeGroup>
```bash cURL
curl -X POST "https://api.valendata.com/v1/skills/hacker-news-jobs/run?max_results=10" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "target_url": "https://news.ycombinator.com/jobs",
    "max_items": 10
  }'
```

```python Python (requests)
import requests

url = "https://api.valendata.com/v1/skills/hacker-news-jobs/run?max_results=10"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
data = {
    "target_url": "https://news.ycombinator.com/jobs",
    "max_items": 10
}

response = requests.post(url, headers=headers, json=data)
print(response.json())
```

```javascript JavaScript (Fetch)
const response = await fetch("https://api.valendata.com/v1/skills/hacker-news-jobs/run?max_results=10", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    target_url: "https://news.ycombinator.com/jobs",
    max_items: 10
  })
});

const data = await response.json();
console.log(data);
```

```typescript TypeScript (Axios)
import axios from 'axios';

const url = 'https://api.valendata.com/v1/skills/hacker-news-jobs/run?max_results=10';
const headers = {
  'Authorization': 'Bearer YOUR_API_KEY',
  'Content-Type': 'application/json'
};
const data = {
  target_url: "https://news.ycombinator.com/jobs",
  max_items: 10
};

axios.post(url, data, { headers })
  .then(res => console.log(res.data))
  .catch(err => console.error(err));
```
</CodeGroup>

## Publishing & Marketplace

Skills can be kept **Private** (accessible only within your workspace) or **Published**:

- **Published Skills**: Get a unique slug (`valendata.com/skills/airbnb-scraper`) that allows teammates and external users to run your automation without viewing sensitive internal prompts.
- **Marketplace**: Monetize or share popular workflows with the Valendata community.
