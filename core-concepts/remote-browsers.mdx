Valendata provisions high-performance, ephemeral Chromium containers running adjacent to the agent runtime for minimal latency and maximum stability.

## Features

- **Anti-Bot & Stealth Engine**: Spoofs realistic browser fingerprints, Canvas/WebGL footprints, and human-like interaction curves.
- **Proxy Management**: Automatic rotation through residential and ISP proxy pools across 190+ countries.
- **Session & Cookie Persistence**: Save login states in encrypted Vault profiles so future runs stay authenticated without repeated 2FA challenges.
- **Live Stream & DevTools**: Watch live browser execution via WebRTC or inspect DOM snapshots and network logs post-run.
