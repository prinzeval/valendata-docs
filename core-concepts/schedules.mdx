Any saved Skill or Workflow can run automatically on a recurring schedule.

## Cron Syntax Support

Valendata supports standard 5-part cron expressions:

```bash
┌───────────── minute (0 - 59)
│ ┌───────────── hour (0 - 23)
│ │ ┌───────────── day of month (1 - 31)
│ │ │ ┌───────────── month (1 - 12)
│ │ │ │ ┌───────────── day of week (0 - 6) (Sunday to Saturday)
│ │ │ │ │
* * * * *
```

### Common Schedules

| Frequency | Cron Expression | Description |
| :--- | :--- | :--- |
| **Every Hour** | `0 * * * *` | Runs at minute 0 of every hour |
| **Daily at 9 AM** | `0 9 * * *` | Runs once every morning at 09:00 UTC |
| **Weekdays Only** | `0 9 * * 1-5` | Runs Monday through Friday |
| **Every 6 Hours** | `0 */6 * * *` | Runs every 6 hours |

<Warning>
Scheduled runs consume credits automatically. Ensure you have sufficient balance or enable **Auto-recharge** in Settings to prevent missed runs.
</Warning>
