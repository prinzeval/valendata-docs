Describe what you need, or do it once in your browser. Valendata turns it into a **skill** that returns clean, structured rows, repairs itself when the site changes, and works as an API and an MCP tool for AI assistants like Claude and ChatGPT.

For example, you describe "list the dentists in Austin on Google Maps". Valendata does the task once in a browser, learns the steps, and saves them. From then on you run the skill with new inputs and get rows back in the same shape every time.

## What you can do with a skill

- **Run it** in the app, from the API, or from an AI assistant such as Claude or ChatGPT.
- **Schedule it** to run every hour, day, or week.
- **Chain it** with other steps in a workflow.
- **Trust it.** When a site changes, Valendata repairs the skill, tests the repair, and saves it as a new version. If it cannot get correct rows, it tells you why instead of returning made-up data. See [Keeping skills working](/concepts/keeping-skills-working).
