# Get Session Status

Returns the current execution state of an active or completed browser session.

### Path Parameters

<ParamField path="id" type="string" required>
  Session ID (`ses_...`).
</ParamField>

<ResponseExample>
```json 200 Response
{
  "session_id": "ses_4f89b102",
  "status": "running",
  "current_step": 3,
  "last_action": "click on #submit-button",
  "screenshot_url": "https://cdn.valendata.com/screenshots/ses_4f89b102_step3.png"
}
```
</ResponseExample>
