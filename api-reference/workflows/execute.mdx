---
title: "Execute Workflow"
api: "POST https://api.valendata.com/v1/workflows/{workflow_id}/execute"
description: "Trigger a multi-step automation workflow execution."
---


Triggers an automated workflow pipeline run.

### Headers

<ParamField header="x-api-key" type="string" required>
  Valendata workspace or workflow API key.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  `application/json`
</ParamField>

### Path Parameters

<ParamField path="workflow_id" type="string" required>
  Unique identifier of the deployed workflow (e.g. `wf_8a7d6e5c`).
</ParamField>

### Body

<ParamField body="inputs" type="object">
  Input parameters passed into Step 1 of the workflow pipeline.
</ParamField>

<ParamField body="webhook_url" type="string">
  Optional URL that receives an HTTP POST when the entire workflow completes.
</ParamField>

<ResponseExample>
```json 200 Response
{
  "run_id": "wfrun_19b84a2",
  "workflow_id": "wf_8a7d6e5c",
  "status": "running",
  "steps_total": 3,
  "created_at": "2026-08-20T13:15:00Z"
}
```
</ResponseExample>
