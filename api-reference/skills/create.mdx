---
title: "Create a skill"
description: "Make a skill from a one-sentence task. Answers at once with a creation id to poll."
openapi: "POST /v1/skills"
---

A cloud browser does the task, learns the steps, and checks them. Read [Get a skill creation](/api-reference/skills/get-creation) about every 30 seconds until `status` is `ready`, `needs_fix`, or `failed`. Send an `Idempotency-Key` so a retry does not start a second creation.

A walkthrough with code, statuses, fields, and limits is in [Create a skill](/guides/create-a-skill#from-a-sentence).

MCP tool: `create_skill`.
