---
title: "Run a Skill"
api: "POST https://api.valendata.com/v1/skills/run"
description: "Execute a published or custom skill via REST API."
---


Trigger an immediate browser automation execution with dynamic parameter inputs.

### Endpoints

- **Run by Slug**: `POST https://api.valendata.com/v1/skills/{slug}/run`
- **Run Ad-hoc Task**: `POST https://api.valendata.com/v1/skills/run`

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer token: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="Content-Type" type="string" required>
  `application/json`
</ParamField>

### Query Parameters

<ParamField query="max_results" type="number" default="10">
  Maximum number of extracted records or items to return.
</ParamField>

### Body

<ParamField body="task" type="string">
  Natural language instruction (required when running ad-hoc tasks without a saved skill slug).
</ParamField>

<ParamField body="inputs" type="object">
  Key-value dictionary supplying parameters for `{{variable}}` interpolations defined in the skill prompt.
</ParamField>

<ParamField body="browser_mode" type="string" default="remote">
  Execution environment: `remote` (isolated cloud browser) or `local`.
</ParamField>

<ParamField body="output_format" type="string" default="json">
  Format of returned extraction: `json`, `markdown`, or `raw`.
</ParamField>
