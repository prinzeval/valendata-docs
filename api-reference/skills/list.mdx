---
title: "List Skills"
api: "GET https://api.valendata.com/v1/skills"
description: "Retrieve all saved and published skills in your workspace."
---


Returns a paginated list of skills owned by your workspace.

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer token: `Bearer val_live_...`
</ParamField>

### Query Parameters

<ParamField query="limit" type="integer" default="20">
  Number of results to return (max 100).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Pagination offset.
</ParamField>

<ResponseExample>
```json 200 Response
{
  "skills": [
    {
      "id": "skl_92ab81c",
      "name": "LinkedIn Job Scraper",
      "slug": "linkedin-job-scraper",
      "is_published": true,
      "created_at": "2026-08-01T12:00:00Z"
    }
  ],
  "total": 1
}
```
</ResponseExample>
