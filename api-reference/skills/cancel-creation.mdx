---
title: "Cancel a skill creation"
description: "Stop a skill that is still being built."
api: "POST https://api.valendata.com/v1/skill-creations/{creation_id}/cancel"
---

Needs `skills:write`. The creation stops at its next step and ends as `cancelled` (its `error` reads "Stopped by you. Nothing was saved."). Credits it already used are not refunded. Only a creation still `queued` or `recording` can be stopped: one that is `validating` or finished (`ready`, `needs_fix`, `failed`) returns `409` and is left as it is. Cancelling again returns the same answer.

Only your own creations. Find the ones still running with [List skill creations](/api-reference/skills/list-creations) and `status=active`.

<ParamField header="Authorization" type="string" required>
  `Bearer vd_sk_...`. See [Authentication](/api-reference/authentication).
</ParamField>

<ParamField path="creation_id" type="string" required>
  The creation's id, from [Create a skill](/api-reference/skills/create).
</ParamField>

<RequestExample>

```bash curl
curl -X POST https://api.valendata.com/v1/skill-creations/sc_3f9a1c2b7d4e5f60/cancel \
  -H "Authorization: Bearer $VALENDATA_API_KEY"
```

</RequestExample>
