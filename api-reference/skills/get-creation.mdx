---
title: "Get a skill creation"
description: "Check a skill creation until it is ready to run or has failed."
openapi: "GET /v1/skill-creations/{creation_id}"
---

`status` moves through `queued`, `recording`, `validating`, then `ready` or `failed`. `slug` is set from `validating` on. A failed creation has `error` and a `diagnosis`. See [Create a skill](/guides/create-a-skill#from-a-sentence).

MCP tool: `get_skill_creation`.
