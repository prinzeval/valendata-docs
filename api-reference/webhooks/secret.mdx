---
title: "Get the signing secret"
description: "The secret that signs your webhook deliveries, for verifying X-Valendata-Signature."
openapi: "GET /v1/webhooks/secret"
---

Use it to verify the `X-Valendata-Signature` header on each delivery. How to verify, with code, is on [About webhooks](/api-reference/webhooks/overview#verify-the-signature).

Needs the `webhooks:read` scope. You can also see the secret in **Settings → API Keys** in the app.
