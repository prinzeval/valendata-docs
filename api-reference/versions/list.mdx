---
title: "List versions"
description: "Every version of a skill, newest first, with the live and pinned ones marked."
openapi: "GET /v1/skills/{slug}/versions"
---

`is_live` marks the version runs use. `is_pinned` marks a pinned one. `reason` says why each was made (`initial`, `heal_fp`, `heal_ai`, `edit`, `restore`, and so on). See [Versions](/concepts/keeping-skills-working#versions).
