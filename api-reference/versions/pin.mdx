---
title: "Pin a version"
description: "Keep a skill on one version, or unpin it."
openapi: "PUT /v1/skills/{slug}/pin"
---

Body `{"version": 3}` pins version 3. `{"version": null}` unpins.

What pinning does is in [Versions](/concepts/keeping-skills-working#versions). To run another version for one call only, pass `version` when you [run the skill](/api-reference/runs/run-skill) instead.

Owner or workspace editor. Needs `skills:write`. MCP tool: `pin_skill_version`, with `skill` and `version`.
