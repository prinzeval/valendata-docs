---
title: "Remove your vote"
description: "Take back your ask for a site request."
api: "DELETE https://api.valendata.com/v1/site-requests/{id}/vote"
---

Your vote comes off the request, so `votes` goes down by one. The request stays for everyone else who asked.

Needs your API key or a signed-in session.

<ParamField header="Authorization" type="string" required>
  `Bearer vd_sk_...`. See [Authentication](/api-reference/authentication).
</ParamField>

<ParamField path="id" type="string" required>
  The request's id, from [List your site requests](/api-reference/sites/list-requests).
</ParamField>

<ResponseField name="ok" type="boolean">`true` when your vote is off.</ResponseField>

<RequestExample>

```bash curl
curl -X DELETE https://api.valendata.com/v1/site-requests/sreq_4b7e9a1c/vote \
  -H "Authorization: Bearer $VALENDATA_API_KEY"
```

</RequestExample>

<ResponseExample>

```json 200
{ "ok": true }
```

</ResponseExample>
