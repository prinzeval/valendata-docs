---
title: "Authentication"
description: "Authenticate API requests using Bearer tokens."
---


Authenticate all API requests by passing your API key in the `Authorization` header:

```bash
Authorization: Bearer val_live_your_api_key_here
```

<Warning>
Never expose your live API key in client-side applications (such as frontend web apps). Always make calls from your backend server or secure edge functions.
</Warning>
