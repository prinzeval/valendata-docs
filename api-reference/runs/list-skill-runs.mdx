---
title: "List skill runs"
description: "A skill's runs, newest first."
openapi: "GET /v1/skills/{slug}/runs"
---

Filter with `status` (comma-separated: `queued`, `running`, `success`, `partial`, `failed`, `cancelled`) and `since`. Page with `limit` (1–100, default 50) and `cursor`.

Each item has `run_id`, `status`, start and finish times, `rows`, `credits`, `failure_class`, `tier_used`, `recipe_version`, `error`, and `run_url`. For the rows themselves, call [Get a run](/api-reference/runs/get).

The skill's owner and workspace see every run. Someone running a public skill sees only their own. Needs `runs:read`. MCP tool: `list_skill_runs`.
